# 缝纫机 · 目送 — H5 作业完整项目

这是一个五页交互式 H5 网页，包含源码、优化后的发布素材和原始素材。无需安装依赖、无需编译；图片和音乐全部随项目保存，不使用会过期的图床。

## 项目内容

- `index.html`：网站入口；HTML 结构、CSS 样式与 JavaScript 交互全部在此文件中，可直接修改。
- `img/`：网页实际使用的图片，已按移动端缩放、裁切透明边缘并优化体积。
- `music.mp3`：网页背景音乐，约 5 分 22 秒，单声道 64kbps 版本。
- `original-assets/`：原始的 13 张 PNG 图片和原始 MP3，便于后续重新制作。
- `.nojekyll`：让 GitHub Pages 按静态网站发布。
- `README.md`：使用、修改与发布说明。

## 已实现的页面

1. 缝纫机加载页：两条蓝色加载轨迹，约 3.9 秒后自动跳转。
2. 相框页：底图 1 秒渐隐；文字 2 秒、3 秒延迟淡入；点击相框跳转。
3. 眼泪页：文字延迟淡入；眼泪约第 3 秒出现，在第 5 秒落到最终位置；点击眼泪区域跳转。
4. 《目送》页：正文 0.5 秒淡入，点击页面进入结尾。
5. 结尾页：歌词和署名依次淡入；点击歌词打开网易云搜索结果。

全局支持 640×1236 等比缩放、音乐循环和右上角音乐开关。

## 在 GitHub Pages 发布（推荐）

1. 登录自己的 GitHub，创建一个 **Public（公开）** 仓库，例如 `fengrenji-h5`。请确认素材允许公开分享；公开仓库内的原图与音乐也可下载。
2. 解压项目压缩包，把解压后的**内容**上传到仓库根目录。根目录必须直接有 `index.html`，不要再套一层文件夹，也不要只上传 ZIP。
3. 在仓库的 **Settings → Pages** 中，选择 **Deploy from a branch**。
4. Branch 选择 `main`（若你的实际分支叫其他名称，选择实际分支），Folder 选择 `/(root)`，点击 **Save**。
5. 等待发布完成，在 Pages 页面复制平台实际显示的 **Visit site** 地址。常见格式为 `https://你的用户名.github.io/仓库名/`，以实际回执为准。
6. 把这个地址发给老师或其他人，访问者不需要登录 GitHub。用手机浏览器检查相框跳转、眼泪跳转和音乐。

GitHub Pages 没有本项目原来图床的 72 小时到期限制，但能否长期访问取决于仓库、账号和平台持续可用，不保证永久。不同地区、网络或微信内置浏览器可能存在访问限制。

> 上传时如果文件选择框隐藏 `.nojekyll`，不必为它卡住；本项目没有以 `_` 开头的资源目录，普通发布仍可工作。请优先确认 `index.html`、`img/` 和 `music.mp3` 已全部上传。

## 本地查看

直接双击 `index.html` 可查看。若本地浏览器限制音频加载，在项目目录运行 `python3 -m http.server 8000`，再打开 `http://localhost:8000/`。

## 如何修改

- 页面的定位和尺寸：修改各个图片、按钮的 `style` 中 `left`、`top`、`width` 等字段（单位是 640×1236 设计画布中的像素）。
- 淡入延时：修改图片的 `--d:2s`、`--d:3s` 等值。
- 加载页跳转时间：修改脚本中 `setTimeout(...,3900)` 的 3900（毫秒）。
- 图片：替换 `img/` 内对应文件，保持名称不变；或修改 `src`。
- 背景音乐：替换根目录 `music.mp3`。
- 歌曲外链：修改脚本中 `window.open(...)` 的地址。当前链接是“缝纫机 刘昊霖”的网易云搜索页，不是具体歌曲分享页。

## 注意与还原范围

- 这是 HTML/CSS/JavaScript 项目，**不是 iVX 原生工程**。老师若明确要求在 iVX 内提交，不能把本项目说成 iVX 工程。
- 按已有步骤与素材还原五页叙事、跳转和主要动画；加载幕布以双蓝色进度条实现，文字位置、眼泪落下幅度作了适配。步骤中关闭自动播放的提示文字改为页面出现后的延迟播放，确保提示能够看到。
- 浏览器通常限制自动播放声音，首次打开后点击屏幕或音乐按钮开启；微信及不同手机上的真实效果需发布后检查。
- 图片文字沿用提供的素材，没有修改原文。发布前请确认原始图片、歌词、《目送》选段及音乐的使用和公开传播权限。
- 更新代码后重新提交到同一仓库，Pages 可继续使用同一个网站地址。
